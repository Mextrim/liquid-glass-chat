# 💧 Liquid Glass Theme для RutonyChat

Премиальная тема оформления чата для **RutonyChat** в ультрасовременном стиле **Liquid Glass** (жидкое стекло / глассморфизм с реалистичным преломлением света и бликами).

---

## ✨ Основные особенности

- 💎 **Эффект жидкого стекла (Liquid Glassmorphism)**: Глубокое матовое размытие фона (`backdrop-filter: blur`), двойная зеркальная фаска и мягкие световые каустики.
- 🌊 **Жидкий световой блик (Liquid Shimmer Sweep)**: Плавная анимация пробегающего светового блика при появлении каждого нового сообщения.
- 🎨 **6 предустановленных стилей стекла**:
  - **Liquid Obsidian** *(по умолчанию)* — стильное темное стекло с идеальной контрастностью для любых игр.
  - **Liquid Crystal** — кристально прозрачное стекло со сверкающими гранями.
  - **Liquid Aurora** — переливающееся северное сияние с пастельно-неоновыми рефлексами.
  - **Liquid Ocean** — свежая лазурно-бирюзовая текучая глубина.
  - **Liquid Sunset** — теплый персиково-янтарный закатный градиент.
  - **Liquid Minimal** — невесомые прозрачные пузыри текста.
- 👤 **Аватары и монограммы**: Глянцевые сквирклы с обрамлением из жидкого стекла. При отсутствии аватара автоматически генерируется стильная монограмма с градиентом под цвет ника.
- 🏷️ **Капсулы площадок**: Стеклянные микро-капсулы с подсветкой под фирменный цвет платформы (Twitch, YouTube, VK Play, Kick, Trovo, TikTok, Discord, Telegram, GoodGame, Nuum, DonationAlerts).
- ↩ **Особые карточки**:
  - **Ответы (Reply)**: Янтарная подсветка с иконкой стрелки и капсулой «Ответ».
  - **Донаты и алерты (Alert / Donation)**: Золотисто-розовое сияние с пульсирующей капсулой «★ Событие / Донат».
  - **Системные сообщения**: Полупрозрачные минималистичные уведомления.
- 🎮 **100% читаемость в OBS**: Двойная мягкая тень текста защищает от засветов на ярких игровых сценах (снег, взрывы, яркое солнце).
- 🛠️ **Интерактивная панель тестирования**: При открытии `template.html` в браузере доступна верхняя плавающая панель для мгновенного теста обычных сообщений, ответов, донатов и автопотока. Панель автоматически скрывается при работе в RutonyChat/OBS или по нажатию клавиши `D` (или `~` / `Ё`).

## 🚀 Установка в RutonyChat

1. Скопируйте папку `lequid` в директорию тем RutonyChat:
   ```
   <Папка RutonyChat>\Themes\lequid
   ```
2. Откройте **RutonyChat** -> **Настройки** -> **Темы оформления**.
3. Выберите тему **lequid** (Liquid Glass).
4. Настройте нужные параметры во вкладке настроек темы:
   - Выберите стиль стекла (`GlassStyle`).
   - Настройте силу размытия (`GlassBlur`) и прозрачность (`GlassOpacity`).
   - Включите/выключите блик (`EnableShimmer`).
   - Настройте шрифты, размеры аватаров, показ значков и время отображения.
5. Нажмите **Применить** / **Сохранить**.

---

## 📺 Настройка в OBS Studio

1. Добавьте новый источник **Браузер (Browser Source)** в сцену OBS.
2. Укажите локальный файл или адрес RutonyChat (обычно `http://localhost:8383/chat.html` или сгенерированный Rutony URL).
3. Рекомендуемые параметры:
   - **Ширина (Width)**: `420` – `520` px
   - **Высота (Height)**: `700` – `900` px
   - **FPS**: `60`
   - Отметьте флажок: **«Выключать источник, когда он невидим»** (по желанию).

## ⚙️ Список настраиваемых параметров (`params.json`)

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| **GlassStyle** | Пресет стиля стекла | `liquid-obsidian` |
| **GlassTintBg** | Базовый цвет стекла | `#0b111e` |
| **GlassOpacity** | Непрозрачность стекла (0–100%) | `75%` |
| **GlassBlur** | Размытие фона (0–35 px) | `16 px` |
| **BorderRadius** | Скругление краев (4–36 px) | `18 px` |
| **EnableShimmer** | Жидкий световой блик при входе | `Вкл` |
| **AccentColor** | Основной акцентный цвет свечения | `#38bdf8` |
| **FontNickname** | Шрифт и размер никнейма | `Outfit 16px` |
| **FontText** | Шрифт и размер сообщения | `Inter 15px` |
| **UserNickColor**| Цвет ника из чата (Twitch/VK) | `Вкл` |
| **TextShadow** | Контрастная тень текста для игр | `Вкл` |
| **ShowAvatars** | Показывать аватары пользователей | `Вкл` |
| **AvatarSize** | Размер аватара | `36 px` |
| **AvatarSquircle**| Скругленный сквиркл (выкл = круг)| `Вкл` |
| **ShowSiteIcons**| Значки платформ (Twitch, YT, Kick)| `Вкл` |
| **ShowBadges** | Значки ролей (Модер, Саб, VIP) | `Вкл` |
| **ShowTimestamp**| Отображать время сообщения | `Выкл` |
| **QtyMessages** | Макс. количество сообщений на экране| `8` |
| **TimeNewMessages**| Время показа сообщения (сек) | `18` |
| **HideMessages** | Автоматически скрывать сообщения | `Вкл` |
